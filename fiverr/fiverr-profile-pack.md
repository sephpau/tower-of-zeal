## 5. First-week checklist

1. Create the account yourself (use a professional username; you can't change it later).
2. Complete profile to 100% — photo, tagline, description, skills, one language. Incomplete profiles rank poorly.
3. Publish Gig 1 (Unity fixes) first — smallest scope, fastest first order.
4. Publish Gigs 2 and 3 within the week; 3+ active gigs = more search surface.
5. Add a gig image to each (1280×769 px). Screenshot of Neon Void gameplay for Gig 1, markofthezeal.com for Gig 2, Ego Run! for Gig 3. I can compose these.
6. Record a 30–60s screen capture per gig if possible — video gigs convert ~2x.
7. Check "Get Briefs" / buyer requests daily and send tailored offers.
8. Reply to every message within 1 hour when awake — response time is a ranking factor.
9. First 10 orders: overdeliver, deliver a day early, politely ask happy buyers to leave a review.
10. After ~10 reviews: raise prices 50–100%.

## Rules that get sellers banned (don't do these)
- Never move payment or chat off Fiverr (they auto-detect emails/links in messages).
- Never deliver empty/placeholder files to stop the clock.
- One account per person, ever.
- Don't buy reviews or review-swap.
